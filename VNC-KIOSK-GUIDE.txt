Настройка VNC в режиме реального времени
1. Установить необходимые пакеты


sudo apt update
sudo apt install -y \
    x11vnc \
    tigervnc-tools \
    openbox \
    gnome-calculator \
    iptables-persistent

Проверить x11vnc:

x11vnc -version

Проверить TigerVNC Viewer:

xtigervncviewer --help


2. Создать пользователя kiosk

Если пользователя ещё нет:

sudo adduser kiosk

Добавить в группы:

sudo usermod -aG video,audio kiosk

Проверить:

id kiosk


3. Создать каталоги
sudo mkdir -p /home/kiosk/.vnc
sudo mkdir -p /home/kiosk/.config/openbox

Выдать владельца:

sudo chown -R kiosk:kiosk /home/kiosk/.vnc
sudo chown -R kiosk:kiosk /home/kiosk/.config



4. Создать пароль VNC

От имени kiosk:

sudo -u kiosk x11vnc -storepasswd /home/kiosk/.vnc/passwd

Вводим пароль:

Enter VNC password:
Verify password:
Write password to /home/kiosk/.vnc/passwd?  [y]/n

Отвечаем:

y

Проверить:

sudo ls -l /home/kiosk/.vnc/passwd

Должно быть примерно:

-rw------- 1 kiosk kiosk ... passwd



5. Проверить физический X-дисплей

Проверить X-сокеты:

sudo ls -la /tmp/.X11-unix/

Должен присутствовать:

X0

Проверить Xorg:

ps aux | grep '[X]org'

Проверить графическую сессию:

who

Проверить X-сокет:

sudo test -S /tmp/.X11-unix/X0 && echo "X0 работает"




6. Проверить DISPLAY

Физический рабочий стол использует:

DISPLAY=:0

Проверить работу X:

sudo -u kiosk env DISPLAY=:0 xset q

Если выводятся:

Keyboard Control:
Pointer Control:
Screen Saver:

значит X11 работает.





7. Настроить Openbox

Создать:

sudo tee /home/kiosk/.config/openbox/autostart > /dev/null <<'EOF'
xset s off
xset -dpms
xset s noblank

while true; do
    dbus-run-session -- /usr/bin/gnome-calculator
    sleep 2
done &
EOF

Права:

sudo chown kiosk:kiosk /home/kiosk/.config/openbox/autostart
sudo chmod +x /home/kiosk/.config/openbox/autostart

Проверить:

sudo cat /home/kiosk/.config/openbox/autostart




8. Настроить запуск приложения

Для тестирования используется GNOME Calculator.

Файл:

/home/kiosk/.config/openbox/autostart

содержит:

while true; do
    dbus-run-session -- /usr/bin/gnome-calculator
    sleep 2
done &

Для kiosk-браузера:

sudo nano /home/kiosk/.config/openbox/autostart

Указать:

xset s off
xset -dpms
xset s noblank

while true; do
    dbus-run-session -- /usr/bin/yandex-browser \
        --kiosk \
        --no-first-run \
        --no-default-browser-check \
        "http://нужный-адрес"

    sleep 2
done &

После изменения:

sudo chown kiosk:kiosk /home/kiosk/.config/openbox/autostart
sudo chmod +x /home/kiosk/.config/openbox/autostart





9. Удалить старый GNOME autostart

Если существует:

/home/kiosk/.config/autostart/calculator.desktop

удалить:

sudo rm -f /home/kiosk/.config/autostart/calculator.desktop

Проверить:

sudo find /home/kiosk/.config/autostart -maxdepth 1 -type f -print 2>/dev/null




10. Проверить порт 2016
sudo ss -lntp | grep 2016

Порт должен быть свободен перед запуском x11vnc.




11. Настроить firewall

Открыть TCP 2016:

sudo iptables -I INPUT -p tcp --dport 2016 -j ACCEPT

Проверить:

sudo iptables -L INPUT -n --line-numbers | grep 2016

Должно появиться:

ACCEPT ... tcp ... tcp dpt:2016




12. Сохранить iptables
sudo netfilter-persistent save

Проверить:

sudo iptables-save | grep 2016

Должно быть:

-A INPUT -p tcp -m tcp --dport 2016 -j ACCEPT



13. Первый запуск x11vnc

Запустить вручную:

sudo x11vnc \
    -display :0 \
    -auth /run/user/1001/gdm/Xauthority \
    -rfbport 2016 \
    -rfbauth /home/kiosk/.vnc/passwd \
    -forever \
    -shared \
    -noshm

Параметры:

-display :0

Физический X11-дисплей.

-auth /run/user/1001/gdm/Xauthority

Авторизация доступа к Xorg.

-rfbport 2016

VNC-порт.

-rfbauth /home/kiosk/.vnc/passwd

VNC-пароль.

-forever

x11vnc продолжает работать после отключения клиента.

-shared

Разрешает несколько подключений.

-noshm

Отключает MIT-SHM.





14. Проверить порт

В другом SSH-сеансе:

sudo ss -tlnp | grep 2016

Ожидается:

LISTEN ... 0.0.0.0:2016 ...




15. Проверить процессы
ps aux | grep '[x]11vnc'

Ожидается процесс:

/usr/bin/x11vnc -display :0 ...

Проверить Openbox:

ps -fu kiosk | grep openbox | grep -v grep

Проверить калькулятор:

ps -fu kiosk | grep gnome-calculator | grep -v grep




16. Подключиться с другого компьютера

На клиенте:

xtigervncviewer 10.202.49.105:2016

или:

vncviewer 10.202.49.105:2016

Ввести VNC-пароль.

На экране должен отображаться текущий физический рабочий стол.





17. Проверить управление
Проверить мышь
Подключиться через VNC.
Переместить мышь.
Убедиться, что движение видно на физическом мониторе.
Проверить клавиатуру
Кликнуть по приложению через VNC.
Набрать текст.
Убедиться, что ввод происходит на физическом компьютере.
Проверить изображение
Открыть приложение на физическом мониторе.
Убедиться, что оно появилось в VNC.
Открыть приложение через VNC.
Убедиться, что оно появилось на физическом мониторе.




18. Создать systemd-сервис

Создать:

sudo nano /etc/systemd/system/x11vnc.service

Вставить:

[Unit]
Description=x11vnc - Share physical X11 desktop
After=display-manager.service
Wants=display-manager.service

[Service]
Type=simple
User=root

ExecStart=/usr/bin/x11vnc \
    -display :0 \
    -auth /run/user/1001/gdm/Xauthority \
    -rfbport 2016 \
    -rfbauth /home/kiosk/.vnc/passwd \
    -forever \
    -shared \
    -noshm \
    -loop

Restart=on-failure
RestartSec=5

[Install]
WantedBy=graphical.target

Сохранить файл.



19. Перечитать systemd
sudo systemctl daemon-reload
sudo systemctl enable x11vnc.service
sudo systemctl start x11vnc.service

Проверить:

sudo systemctl status x11vnc.service




20. Проверить порт
sudo ss -tlnp | grep 2016

Ожидается:

LISTEN ... 0.0.0.0:2016 ...



21. Проверить после перезагрузки

Перезагрузить систему:

sudo reboot

После загрузки проверить:

sudo systemctl status x11vnc.service --no-pager

Проверить порт:

sudo ss -tlnp | grep 2016

Проверить X:

sudo ls -la /tmp/.X11-unix/

Должен присутствовать:

X0

Проверить x11vnc:

ps aux | grep '[x]11vnc'

Проверить Openbox:

ps -fu kiosk | grep openbox | grep -v grep

Проверить приложение:

ps -fu kiosk | grep -E 'yandex-browser|gnome-calculator' | grep -v grep




22. Подключение после перезагрузки

На клиенте:

xtigervncviewer АЙПИ:2016

Ввести VNC-пароль.

27. Итоговая схема
                    WEBKIOSK
                       │
                       │
                 Xorg DISPLAY :0
                       │
              ┌────────┴────────┐
              │                 │
        Физический         x11vnc
         монитор              │
              │                │
              │           TCP 2016
              │                │
              │                ↓
              │       TigerVNC Viewer
              │                │
              └───────┬────────┘
                      │
                один рабочий стол

Компоненты:

Xorg :0
    ↓
Openbox
    ↓
kiosk application
    ↓
x11vnc
    ↓
TCP 2016
    ↓
TigerVNC Viewer
